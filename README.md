# 민희의 세 번째 생일

## 배포 및 실행

웹사이트는 정적 파일만으로 동작하며 `start.bat`에 의존하지 않습니다. HTTPS를 지원하는 일반 정적 호스팅에 아래 항목만 배포하면 됩니다.

- `index.html`
- `app.js`
- `camera.js`
- `styles.css`
- `site-data.js`
- `song.mp3`
- `img-preview` 폴더
- `frame` 폴더
- `과거생일케이크` 폴더

원본 `img` 폴더, `build-previews.py`, `update-and-open.ps1`, `start.bat`는 배포하지 않아도 됩니다. 카메라 권한을 사용하려면 `file://`로 직접 여는 대신 HTTPS로 배포된 주소 또는 localhost에서 열어야 합니다.

## 사진 추가 및 배포본 갱신

- 새 원본 사진을 `img` 폴더에 넣습니다.
- `update-and-open.ps1 -GenerateOnly`를 실행합니다.
- 새 미리보기와 `site-data.js`가 생성되면 위의 배포 항목만 다시 올립니다.

사진 개수 제한은 없습니다. Python과 Pillow를 사용할 수 있으면 원본을 건드리지 않고 `img-preview`에 최대 560px의 재생용 복사본을 생성하며, 변경되지 않은 사진은 다시 만들지 않습니다. 웹사이트의 배경과 Gallery는 언제나 `img-preview`만 사용합니다.

지원하는 사진 형식은 `JPG`, `JPEG`, `PNG`, `WEBP`, `GIF`, `AVIF`입니다.

## 로딩과 Gallery

첫 암호 화면에서 미리보기 사진, 프레임, 과거 케이크와 음악을 모두 불러옵니다. 준비가 끝나야 확인 버튼이 활성화됩니다. 배경에는 PC 28장, 모바일 24장을 3초간 동시에 표시합니다. 현재 보이는 사진 전체가 천천히 사라진 뒤 다음 순서의 사진 묶음으로 한꺼번에 바뀌고, 다시 천천히 나타납니다.

암호를 맞히면 카메라가 바로 실행되지 않고 중앙 제목과 배경 사진만 있는 메인 화면이 열립니다. 화면 아래의 `열어보기`를 누르면 케이크 사진, 오늘의 우리, Gallery를 선택하는 하단 메뉴가 나타납니다. 촬영 기능을 선택한 경우에만 카메라를 켜며, `← 메인`으로 돌아가면 카메라를 즉시 종료합니다.

Gallery는 처음 36장을 보여 주고 `사진 더 보기`를 누를 때마다 다음 36장을 추가합니다. Gallery를 보는 동안에는 카메라를 잠시 끄고, 촬영 탭으로 돌아가면 자동으로 다시 켭니다. 완성 사진에서 `사진 저장`을 누르면 다운로드와 함께 해당 사진을 브라우저의 IndexedDB에도 보관합니다. 보관된 사진은 Gallery 맨 앞에 추가되며, 교체되는 일반 배경 사진과 별도의 상단 레이어에서 사라지지 않고 계속 떠다닙니다. 케이크 결과물은 전체 세로 스트립이 보이도록 일반 폴라로이드보다 훨씬 긴 비율로 표시됩니다. 같은 브라우저에서는 새로고침 후에도 유지됩니다. 정적 사이트이므로 다른 기기나 브라우저에는 자동으로 공유되지 않습니다.

## 촬영 탭

### 케이크 사진

정사각형(1:1)으로 촬영하거나 `사진 올리기`로 기기의 케이크 사진을 선택할 수 있습니다. 저장 결과는 `2024.jpg` → `2025.jpg` → 이번 촬영 또는 업로드 사진 순서의 세로 스트립이며, 각 사진 위에 연도가 표시됩니다. 맨 아래에는 `Happy Birthday 민희 ♥` 문구가 들어갑니다. 사진 업로드 기능은 케이크 사진 탭에서만 표시됩니다.

### 오늘의 우리

기존 즉석사진 형식을 유지합니다. `frame` 폴더의 번호 프레임을 선택하고 위치와 크기, 하단 문구를 조정한 뒤 날짜가 들어간 PNG로 저장할 수 있습니다. 촬영을 누르면 카메라 화면 대신 전용 처리 화면을 보여 준 뒤 완성 결과로 전환합니다.

`start.bat`는 배포용 필수 파일이 아니라 로컬에서 목록을 갱신하고 테스트 서버를 여는 편의 도구로만 남겨 두었습니다.
